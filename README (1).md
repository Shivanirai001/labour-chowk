# 🏗️ Labour Chowk

A platform to find and register skilled workers in Faridabad and nearby areas.

## 🔗 Live Site
[Click here to visit Labour Chowk](https://labour-chowk.vercel.app)

## 📌 About
Labour Chowk connects daily wage workers (plumbers, electricians, painters, carpenters and more) with people who need their services in Faridabad, Ballabhgarh, NIT Faridabad and nearby areas.

Workers can register themselves for free. Employers can search and contact workers directly via call or WhatsApp.

## ✅ Features
- Browse available workers by area and skill
- Search workers by name
- Filter by skill type (plumber, electrician, painter, etc.)
- WhatsApp and Call buttons on every worker card
- Worker registration form
- Admin panel to approve or remove workers
- Works on mobile and desktop
- Data stored in Supabase (free database)

## 📁 Pages
| Page | Description |
|---|---|
| `index.html` | Home page — browse and search workers |
| `register.html` | Workers register themselves here |
| `admin.html` | Admin approves or removes registrations |
| `firebase-config.js` | Supabase connection keys |

## 🛠️ Built With
- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript
- Supabase (free database)
- Vercel (free hosting)

## 🚀 How to Run Locally
1. Download or clone this repository
2. Open `firebase-config.js` and add your own Supabase URL and Key
3. Open `index.html` in your browser
4. Done — no installation needed

## 🔒 Admin Panel
- Open `admin.html` in browser
- Default password is set inside `admin.html`
- Approve pending workers so they appear on the main listing
